# Project Context: NASA Mission Spending Tracker

## 1. Project Goal

The goal is to build an object-oriented Python system for generating a static site of structured JSON fiels corresponding to NASA science missions. The architecture emphasizes a clean separation of concerns, with distinct classes for data representation, data processing, and rendering.
---

## 2. Coding Style & Instructions

- Implement the design using clean, pythonic, object-oriented principles.
- Adhere strictly to **PEP 8**.
- Use `pydantic` for data validation.
